# HoneyForge 🍯🛡️

**MVP платформы централизованного управления ловушками-приманками (Honeypots).**
Разработано для III Межрегионального Хакатона UmirHack.

## Архитектура проекта

Система разделена на два изолированных сетевых контура (в рамках Docker):
1. **`dmz-network` (Сеть приманок):** Смотрит "наружу". Здесь работают открытые порты ловушек (Low/Medium interaction), с которыми взаимодействует атакующий.
2. **`mgmt-network` (Скрытая сеть управления):** Изолированная внутренняя сеть. Связывает Агентов с Центром управления (API + БД). Атакующий не видит этот контур. 

Трафик от агентов к центру маскируется (Nginx Reverse Proxy) под легитимные запросы, чтобы скрыть факт наличия системы управления (Требование MASK-2).

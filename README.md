## ⚡ Ключевые возможности и реализация

### 1. Строгая сетевая изоляция и маскировка (MASK-2)
- Контейнер ловушки `agent_low` находится **исключительно** в сети `dmz-network`. Он не имеет прямого доступа к PostgreSQL или Control API.
- Трафик телеметрии маскируется под обычные запросы за CDN-ассетами: `POST /cdn/assets/v2/metrics.json`.
- В случае компрометации ловушки злоумышленник заперт в DMZ и не может атаковать ядро системы.

### 2. Реалистичные интерактивные ловушки
- **SSH (2222):** 
  - Персистентный RSA-ключ хоста (anti-fingerprinting: отпечаток не меняется при перезапуске).
  - Прием любых учетных данных с логированием логинов и паролей.
  - Поддержка как интерактивного PTY-терминала с обработкой Backspace, Ctrl+C, так и non-interactive команд (`exec`).
  - Ловушки-приманки (Honeyfiles): `passwords.txt`, `.env` с фейковыми токенами AWS и БД.
  - Детектирование загрузки вредоносов (`wget`, `curl`) с эмуляцией скачивания и логированием ссылки.
- **Telnet (2323):**
  - Эмуляция BusyBox ash роутера для перехвата атак ботнетов (Mirai, Mozi).
  - Логирование попыток входа и команд (`cat /proc/mounts`, `enable`, `system`).
- **FTP (2121):**
  - Полноценная машина состояний RFC-959 (баннер vsFTPd, диалог `USER` $\rightarrow$ `PASS` $\rightarrow$ `SYST` $\rightarrow$ `PWD` $\rightarrow$ `QUIT`).

### 3. Отказоустойчивая буферизация
- При недоступности центра агент сохраняет события в локальную SQLite-базу (`buffer.db`) в режиме WAL.
- Фоновый воркер с джиттером выгружает накопленные события при восстановлении канала связи.

### 4. Автономный Threat Intelligence & GeoIP
- Обогащение событий: страна, эмодзи-флаг, город и координаты (работает автономно даже без выхода в интернет).
- Автоматическая классификация по матрице **MITRE ATT&CK**:
  - `T1046: Network Service Discovery` (сканирование портов)
  - `T1110: Brute Force Credentials` (перебор SSH/FTP/Telnet)
  - `T1059: Unix Shell Command Execution` (выполнение команд)
  - `T1552: Unsecured Credentials Access` (чтение passwords.txt / .env)
  - `T1105: Ingress Tool Transfer` (загрузка малвари через wget/curl)

### 5. Next-Gen Cyberpunk SOC Dashboard
- **World Attack Map:** Интерактивная карта атак (Leaflet) с анимацией эпицентров и координатами.
- **Live Stream:** Реалтайм-лента событий по WebSocket с цветовой индикацией серьезности (Critical, High, Warning, Info).
- **Звуковой синтезатор:** Аудио-сигнализация критических атак на базе Web Audio API.
- **Аналитика:** Распределение по протоколам (Doughnut Chart), топ паролей ботнетов, топ атакующих IP.
- **Защита от XSS:** 100% экранирование всех пользовательских полей.
- **Экспорт отчетов:** Скачивание структурированного JSON-отчета (`/api/export`) для передачи в SIEM.

## 🚀 Быстрый запуск

### 1. Запуск платформы
В директории `honeyfordge` выполните:

```bash
docker-compose up -d --build
```

После старта будут доступны сервисы:
- 🌐 **SOC Консоль (Web Dashboard):** [http://localhost:8080](http://localhost:8080)
- 🔒 **SSH Ловушка:** `localhost:2222`
- 📁 **FTP Ловушка:** `localhost:2121`
- 📡 **Telnet Ловушка:** `localhost:2323`

### 2. Запуск демонстрационного симулятора атак
Для эффектной презентации платформы запустите скрипт генерации атак:

```bash
python3 demo_attacks.py
```

Скрипт проведет атаку на FTP, Telnet и SSH ловушки, а также сгенерирует международную телеметрию для заполнения карты угроз на дашборде.

## 🔌 API Справка

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/cdn/assets/v2/metrics.json` | Скрытый канал приема телеметрии от агентов (MASK-2) |
| `POST` | `/cdn/assets/v2/register.json` | Авторегистрация и Heartbeat узлов |
| `GET` | `/api/honeypots` | Список активных приманок и их сервисов |
| `GET` | `/api/events` | История событий с фильтрацией по типу и поиском |
| `GET` | `/api/stats` | Сводная аналитика (топ IP, топ паролей, протоколы) |
| `GET` | `/api/export` | Экспорт всех событий в JSON для SIEM |
| `DELETE` | `/api/events/clear` | Очистка истории для сброса демо-стенда |
| `WS` | `/ws/events` | WebSocket-поток инцидентов в реальном времени |
